# История: «Фил на компьютере» — WeChat сотрудников (14.11.2026, №559)
Когда: Фил читает WeChat, скачать каталоги из WeChat, написать поставщику в WeChat, установить Фила на компьютер
---
Решение руководителя: у каждого сотрудника свой компьютер (Windows) и свой рабочий WeChat (не корпоративный, личного там нет). Ставят «Фила» ярлыком — вместе ставится всё нужное для работы с WeChat; основной помощник — Фил. Делать оба способа сразу (по версии WeChat и «по экрану»). Руководитель предупреждён о риске блокировки WeChat и согласился. Письма поставщикам — после подтверждения сотрудника.
Сделано: desktop/fil_pc (core.py — связь, подключение, поручения; wx_engine.py — WeChat 3.9 через wxauto, 4.0.5 через wxauto4, иначе снимки экрана + распознавание в магазине; файлы — из папок WeChat; fil_pc.pyw — окошко, ожидание тишины мыши, самообновление). Установка: store/app/pc/ (ustanovit-fila.cmd → install.ps1: Python 3.12 в папку пользователя, библиотеки с запасными зеркалами Китая, ярлыки «Фил»/«Космос» окном браузера, помощник в автозагрузку). Магазин: store/api/pc_link.php — подключение кодом, очередь поручений, приём переписки в itc_wc_chat/itc_wc_msg (как WeCom), файлы → itc_fc_file + история поставщика; инструменты Фила/«Космоса»: pc_pair, wechat_read, wechat_files, wechat_send, wechat_status, pc_unpair.
Не проверено на настоящем WeChat (у Claude нет Windows): первая проверка — в офисе через 3 дня (17.11.2026).
