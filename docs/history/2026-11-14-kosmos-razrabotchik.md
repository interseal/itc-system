# История: «Космос»-разработчик (14.11.2026, №547, сервер 0.3.9)
Когда: Космос разработчик, почему Космос не может обновлять, Claude Code на сервере, лимит расходов разработчика
---
Вопрос руководителя: почему «Космос» не умеет сам обновлять систему, если читает навыки Claude. Ответ: навык — знание, а не инструменты; модель та же, разница в рабочем месте.
Решение руководителя: сделать «Космоса» полноценным разработчиком, только для руководителя; для сотрудников — как раньше. Защита согласована: ставит обновление только руководитель кнопкой; правки — в ветку kosmos/N, в главную — только после проверок; ключи, сейф и оплаты не трогает; лимит $30 в день.
Сделано: на сервере Claude Code от отдельного пользователя kosmosdev (ключей сервера не видит, в GitHub сам не пишет), модель на выбор (Opus, Sonnet, Fable), свои помощники; правила — kosmos/dev/RULES.md; настройки «Космоса» → «Разработчик»: поручение, расход, лимит, ключ записи в GitHub (руководитель добавляет один раз с галочкой Allow write access).
