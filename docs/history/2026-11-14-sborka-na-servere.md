# История: обновления собирает сервер (14.11.2026, №545)
Когда: почему нужен был ноутбук, сборка обновлений на сервере, кнопка установить, ключи подписи
---
Вопрос руководителя: зачем ключи с ноутбука, если есть сервер в Сингапуре. Ответ: ключи подписи держали только на ноутбуке, а рабочее место Claude видит из интернета только GitHub.
Решение руководителя: перенести сборку на сервер. №545 (последний раз ключами с ноутбука): сервер 0.3.7 сам собирает и подписывает обновления из GitHub (releases/N.json), магазин отдаёт ему ключ обновлений, свой ключ пакетов сервер создаёт сам; копии ключей — в сейфе «Авто». Руководитель ставит кнопкой «Установить» на странице «Обновления».
Следующее по решению руководителя: сборка Android-приложений на сервере (сервер помощнее — купить), пароли ключа Android руководитель вписывает в сейф сам.
