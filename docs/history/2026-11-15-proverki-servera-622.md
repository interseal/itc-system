# Почему поручения №11 и №12 получили checks_failed (проверки сервера) и как починили (№622)
Когда: checks_failed проверки сервера не прошли run_tests.py «Сейчас в работе», ключи сервера [] ключи Claude — каждый своей записью состояние для настроек уже работает другой проход kosmos-agent.lock Permission denied runuser may not be used by non-root users Pillow PIL нет
---
15.11.2026, поручение руководителя: №11 (лента без <invoke>) сообщил «выпущено №622», а статус checks_failed и обновления нет.
- Правка №11 тут ни при чём: run_tests.py падал и на чистой main. Проверки сервер гоняет только если поручение меняло kosmos/ (поручения №4–10 его не трогали — поэтому раньше «всё проходило»), и гоняет их от kosmosdev (runuser -u kosmosdev), а тесты были рассчитаны на root.
- Причина 1 (раздел 13, сейф): агент берёт замок sys_get_temp_dir()/kosmos-agent.lock; в /tmp он от root (настоящий агент) → у kosmosdev Permission denied → «уже работает другой проход» → сейф не заполнен → три ✗ из сообщения и падение на fake_bws.json. Даже под root тест мог столкнуться с идущим проходом настоящего агента. Исправлено: run_tests.py даёт всем своим процессам TMPDIR=/tmp/kosmos_test/tmp — свои замки.
- Причина 2 (разделы 17–19, разработчик): агент зовёт «timeout N runuser -u kosmosdev -- claude…» с постоянным PATH; runuser у не-root не работает. Под не-root тест подкладывает свои runuser и timeout (TMP/bin) — убирают «runuser -u ИМЯ --» и записывают, кого просили; добавлена проверка «агент просил запуск от kosmosdev». Под root — всё по-настоящему.
- Причина 3 (разделы 20–21, файлы): на сервере нет Pillow (python3-pil). Тест рисует картинки через ImageMagick (convert/identify), если PIL нет; проверки те же.
- agent.php НЕ менялся (его правки ждут одобрения руководителя). Итог: 188 ✓ на №11, 191 ✓ на №12 с этими правками.
- Заодно в №622: fp_think (строка-пояснение шага в ленте) тоже идёт через itcai_clean.
- №12 (ветка kosmos/12) построен поверх №11; мои правки накладываются на неё без конфликтов (проверено git apply -3). №623 ставить после №622.
