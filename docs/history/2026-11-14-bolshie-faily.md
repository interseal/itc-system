# 14.11.2026 — большие файлы до 500 МБ (№581, сервер 0.4.6)

Руководитель: «ограничение на объём должно быть как у Claude на компьютере — грузить любой объём». Раньше было 20 МБ на файл, причём одинаково на телефоне и на компьютере (ограничение стояло в магазине).

Как теперь:
- Файл больше 15 МБ (в CRM — больше 12 МБ) телефон или компьютер шлёт кусками по 2 МБ:
  - `fc_up_start` → `fc_up_part` (смещение off; если кусок повторился после обрыва — пропускаем) → `fc_up_done`;
  - потолок — 500 МБ (`FF_BIG_MAX`);
  - недогруженное удаляется через сутки (`uploads/fil_files/up`).
- Файл до 20 МБ после сборки обрабатывается как обычный `fc_file` (`goto fc_file_go`).
- Больший сохраняется целиком с пометкой «обработать инструментом files».
- `ag_files` такой файл в память не читает: передаёт серверу разовую ссылку `ff_dl` (HMAC на ключе шлюза, живёт 2 часа).
- `gw_media` на сервере (`kosmos/lib/media.php`) скачивает файл по ссылке только с itcpartner.store, до 500 МБ (`MEDIA_MAX_URL`).
- Тесты: `flow_e2e` раздел 23.
