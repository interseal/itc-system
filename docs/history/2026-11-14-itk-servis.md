# 14.11.2026 — «ИТК Сервис»: основа для сферы услуг, первое приложение «Парикмахерские» (№597)

Задумка руководителя: приложения для шиномонтажа, парикмахерских и цветочных магазинов в «Моих приложениях» ИТК. Бизнес заводит себя (юрлицо, адрес, фото, цены), клиент по геолокации видит, где рядом свободно, и записывается; предоплату задаёт сам бизнес. ИТК берёт 5% только с того, что прошло через нас (95% — бизнесу). Позже — поставщики расходников с прайсами (тоже 5% с заказов). Страна и платёжный терминал — позже («делаем саму базу»). Начали с парикмахерских.

## Что сделано
- `store/api/svc.php` — одна основа для трёх видов (`kind`: salon / tire / flower). Таблицы: `svc_biz` (бизнес, юрлицо, точка, часовой пояс, валюта, часы, предоплата, администраторы), `svc_staff` (мастера/посты, свои часы), `svc_service` (услуги, варианты цены — длина волос, радиус колеса), `svc_booking` (записи: из приложения, без записи, по телефону), `svc_pay` (деньги: amount, fee 5%, payout 95%, выплата due/sent).
- Свободные окна шагом 15 минут по часам мастера и записям; две записи на одно время невозможны (блокировка строки мастера).
- «Светофор» для карты: зелёный — свободно в ближайшие 15 мин, жёлтый — до 90 мин, красный — дальше/мест нет, серый — закрыто или бизнес не открывал кабинет больше 3 дней (чтобы цвет не врал).
- Деньги: `sv_pay_settle()` делит 5/95; отмена заранее или отмена бизнесом — возврат клиенту, наши 5% не берём; поздняя отмена — предоплата остаётся бизнесу.
- Терминал — отдельный файл `api/svc_pay_provider.php` с `svc_provider_start()` (ссылка на оплату) и `svc_provider_hook()` (подтверждение → `action=pay_hook`). Нет файла — запись без онлайн-оплаты, предоплата на месте.
- `store/apps/salon/` — приложение: «Рядом» (карта Leaflet/OpenStreetMap + список; без карты работает список), «Мои записи», «Мой салон» (Сегодня, Услуги, Мастера, Профиль, Деньги), «ИТК» для руководителя. Тот же файл годится для `/apps/tire/` и `/apps/flower/` (вид — из адреса, подписи — LB).
- В «Моих приложениях» — пока только руководителю.
- Проверки: `kosmos/tests/svc_api_test.py` (28), `kosmos/tests/ui/salon_ui.py` (14).
