# Как выпускается обновление Экосистемы
Когда: спрашивают, как ставится обновление, что такое obnovlenie_N.zip, почему обновление не ставится, какой номер следующего обновления
---
1) Обновление — архив obnovlenie_N.zip. Ставит его только руководитель: Экосистема → Обновления → выбрать файл. Ставится строго по порядку: №N только после №N−1 (иначе страница откажет).
2) Архив подписан ключом обновлений (UPD_KEY). Чужой или испорченный архив не ставится.
3) Если внутри есть новая версия сервера «Космоса», сервер в Сингапуре сам забирает её из магазина в течение 10 минут и проверяет подпись (ключ KOSMOS_SIGN_KEY).
4) Что стоит сейчас — первая строка страницы «Обновления»: «Сейчас установлено: обновление №…». Версию сервера «Космоса» видно там же, в строке «Сингапур».
5) Перед выпуском Claude сверяет файлы на сайте с хранилищем кода на GitHub (interseal/itc-system) и прогоняет проверки; после выпуска записывает всё в паспорт системы и «Сейчас в работе».
6) Не ставится — смотрите красную строку на странице: обычно это неверный номер (пропущено предыдущее) или файл скачан не полностью.
