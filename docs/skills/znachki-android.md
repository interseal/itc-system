# Значки Android-приложений по эталону
Когда: делаешь новое Android-приложение, меняешь значок или выпускаешь Android-обновление.
---
1. Эталон утвердил руководитель 14.11.2026. Он лежит в android/znachki/ в GitHub и в копии кода на сервере «Космоса». Там же README.md с пропорциями и картинка etalon_vse.png со всеми значками.
2. Главное:
   - белый шар ИТК занимает 52,8 % полотна, как в «Экосистеме», по центру;
   - фото человека — в белой рамке, как у «Фила», 55,3 % полотна;
   - любой другой знак — того же размера, что и шар;
   - фон одним цветом во весь значок, без белых полей по краям.
3. Новое приложение: python3 kosmos/tools/new_android_app.py … --kind shar|foto|logo. Значок делается по эталону сам.
4. Поменять значок: python3 kosmos/tools/icon_kit.py make --key <имя> --kind shar|foto|logo [--image файл] --color "#RRGGBB".
5. Перед выпуском: python3 kosmos/tools/icon_kit.py check. Всё, что не по эталону, исправь или спроси руководителя.
6. Свой размер или вид значка без согласия руководителя не придумывай.
