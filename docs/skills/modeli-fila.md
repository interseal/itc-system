# Модели «Фила»: роли китайских ИИ, ключи, проверка, лимит
Когда: модели Фила, роль фото, Qwen-VL, Kimi, Doubao, GLM, ключ Qwen, ключ Moonshot, ключ Z.ai, дневной лимит Фила, сменить модель роли, cn_text
---
1) Где: «Обновления» → «Модели Фила». Код — store/api/fil_roles.php, API — kb.php (fr_*).
2) Роли по правилам, без лишнего запроса к ИИ: есть снимок → «Фото» (Qwen-VL, запасная GLM-4.5V); текст > 30 000 знаков → «Длинные тексты» (Kimi); письмо фабрике / перевод → инструмент cn_text (Qwen); «спасибо/привет/ок» → «Простые ответы» (Doubao). Остальное и все действия — DeepSeek.
3) Любой отказ, 60 с, нет ключа, проверка «не подходит», лимит дня — делает DeepSeek. Новую роль добавляй так же: fr_models(роль) пусто → обычный путь.
4) Ключи — в itc_secret frk_<поставщик>, наружу только 4 знака. Новый ключ сбрасывает проверку моделей этого поставщика.
5) Новая модель: строка в FR_MODELS (поставщик, имя, цена вход/выход за 1М, 'v' если видит картинки), потом «Проверить» в окне.
6) Расход: itc_fr_use (DeepSeek — роль main, в лимит не входит), в журнале itc_fc_log.ai — кто что сделал и сколько стоило.
7) Международные платформы без китайских документов: Alibaba Cloud Model Studio (dashscope-intl), Moonshot (api.moonshot.ai), Z.ai (api.z.ai), BytePlus ModelArk (Doubao), MiniMax (api.minimax.io), StepFun (api.stepfun.ai). Hunyuan и Qianfan — нужен китайский аккаунт. Yi (01.AI) — API закрыт (410).
