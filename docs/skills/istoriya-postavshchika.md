# История поставщика: занести и найти
Когда: занеси в базу, скриншот переписки, новый каталог или прайс от поставщика, работали ли мы с поставщиком, какие цены давал, последнее предложение
---
1) Занести: sup_note {sup, kind (цены/каталог/условия/сроки/…), text — суть своими словами (цены с валютой, MOQ, сроки, оплата), at — дата события, files — id приложенных файлов, deal — если по сделке}. Поставщика определить самому (suppliers); если нет в базе — add_supplier.
2) Найти: sup_history {sup, q, kind} — записи + переписка WeChat из CRM + сделки + файлы карточки, новые сверху. Отвечать с датами, сравнивать цены по времени.
3) Страница: itcpartner.store/eco/sup.html?id=<поставщик>; из CRM — 🕘 у поставщика в сделке.
4) Скрыть ошибочную запись может только руководитель (sh_hide). Таблица: itc_sup_log (store/api/sup_hist.php).
