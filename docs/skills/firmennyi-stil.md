# Документы в фирменном стиле ИТК
Когда: сделать КП, счёт, запрос цены поставщику; поменять логотип или цвета
---
1) Документы — только инструментами: make_kp (КП, комплексное КП), make_invoice (счёт), make_request (коммерческий запрос поставщику; для Китая lang=en). Не составлять текстом «от себя».
2) Стиль — одна база (store/api/brand.php, itc_secret[brand]): цвета сайта #0d2a6b / #128c04, логотип с itcpartner.ru или загруженный руководителем, слоган, подпись.
3) Поменять — только руководитель: brand_set {logo_file (id приложенной картинки), company (чья), primary, accent, slogan, slogan_en, sign_name, sign_title}. Посмотреть — brand.
