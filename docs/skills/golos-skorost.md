# Скорость голоса «Фила» и «Космоса»: где теряется время
Когда: голос долго, медленно отвечает, долго распознаёт, долго молчит перед ответом, ускорить ответ помощника, кеш промпта
---
1) Слушание: store/apps/fil/voice.js и store/apps/kosmos/voice.js (одинаковые, кроме имён). В приложении — мост AndroidSpeech (SpeechHelper.java): listen() — тишина 1 с, listenLong() — 4 с (диктовка, решение №617, не уменьшать без руководителя). keep:true — конец только по второму нажатию; без keep — 1,2 с без новых слов (таймер QT). После «стоп» — 0,25/0,7 с, не больше.
2) Браузер: запись → sp_hear (Яндекс). Длинная диктовка — куски на паузах (после 15 с), иначе в конце долгое распознавание.
3) Ответ: ag_run в store/api/flow.php. Один ход модели = 2–8 с. Несколько независимых инструментов — {"tools":[…]} (AG_MULTI). Простое — сразу (AG_FAST_RULES).
4) Кеш: всё меняющееся в правилах — только ПОСЛЕ AG_DYN (время, дела напарника, навыки). Сервер «Космоса» (gw_sys_cut) ставит два блока с cache_control. Новое меняющееся в середину правил не вставлять — кеш перестанет работать.
5) Озвучка: V.ttsParts — первое предложение отдельно; куски заказываются сразу, играются по очереди.
6) После правок voice.js: поднять ?v= в fil, kosmos, crm, draw index.html и имена кешей в их sw.js.
