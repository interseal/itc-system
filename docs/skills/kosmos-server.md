# Сервер «Космоса» в Сингапуре: как он устроен
Когда: спрашивают про сервер в Сингапуре, работает ли Космос, нет связи с сервером, версия сервера, копии базы, GitHub на сервере
---
1) Адрес kosmos.itcpartner.store (Aliyun, Сингапур). Там живут «Космос», его память, ключи Claude и общие навыки «Фила» и «Космоса».
2) Проверка: https://kosmos.itcpartner.store/api.php?a=health — ok, версия, worker (фоновые задачи), key (есть рабочий ключ Claude).
3) Агент сервера раз в минуту сообщает магазину, что жив (страница «Обновления» → строка «Сингапур»: на связи, версия, место, нагрузка, копия данных, копия кода с GitHub).
4) Раз в 10 минут: новые версии из магазина (с проверкой подписи), рабочая копия кода из GitHub (/srv/itc-system, только чтение), отправка в сейф Bitwarden.
5) Каждую ночь (03:00–05:00 по Бишкеку) копия базы уходит в магазин, хранятся 7 последних. Новый сервер поднимается той же командой установки, память — из копии.
6) Навыки хранятся на сервере и копией в магазине: если сервер недоступен, «Фил» и «Космос» работают по копии.
7) Нет связи больше 3 минут — строка «Сингапур» красная. Сначала проверить консоль Aliyun (сервер включён, оплачен), потом сообщить Claude.
