# Деньги Claude: сколько осталось на счёте
Когда: спрашивают баланс Claude, сколько денег на API, хватит ли денег, кончились деньги, пополнить Claude
---
1) Остаток Claude через API не отдаёт. Точная сумма — только на platform.claude.com → Settings → Billing → Credit balance.
2) Сервер «Космоса» сам считает цену каждого своего ответа по ценам Claude (Haiku, Sonnet, Opus, Fable) и присылает расход в магазин.
3) Страница «Обновления» → «Claude — деньги на счёте»: потрачено сегодня, за 7 и 30 дней. Если руководитель вписал остаток со страницы Billing, видно «осталось ≈ $…» и на сколько дней хватит.
4) После каждого пополнения остаток нужно вписать заново (кнопка «Пополнили счёт? Указать новый остаток»).
5) Ниже $5 или меньше 3 дней — цифра красная, пора пополнять. Если Claude ответил «денег нет» — красная надпись; «Космос» сам переходит на запасной ключ, если он есть.
6) Ключи одного счёта показываются вместе (счёт сервер узнаёт из ответа Claude).
