# Навыки Claude для «Космоса» и «Фила»

Здесь Claude (помощник, который строит систему ИТК) записывает, что он умеет и как устроена система.
Сервер «Космоса» в Сингапуре раз в 10 минут забирает GitHub и переносит каждый файл в общие навыки
«Космоса» и «Фила» (автор — Claude). Копия навыков есть и в магазине. Изменили файл — навык обновится,
удалили файл — навык уйдёт.

Формат файла: первая строка `# Название`, строка `Когда: …` (когда применять), затем `---` и шаги
(не длиннее 1500 знаков).
