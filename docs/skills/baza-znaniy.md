# База знаний ИТК: где знания помощников и как подключить другую модель
Когда: где хранится памятка, выученное, правила Фила и Космоса, база знаний, сменить модель ИИ, подключить другую модель, выгрузить знания, восстановить базу знаний, копии базы знаний
---
1) Все знания — в базе магазина, таблица itc_kb (api/kb_lib.php): памятка, выученное, правила помощников, история поручений разработчику, память «Космоса» с сервера. Навыки — сервер «Космоса» + копия itc_skill_copy, журнал — itc_fc_log / itc_ks_log. От модели ИИ ничего не зависит.
2) Подсказку любого помощника собирают kb_prompt() и kb_rule(): новое правило в коде — тоже через kb_rule('ИМЯ', ИМЯ, true), иначе его не будет в базе и выгрузке.
3) Правило в коде поменяли — база обновится сама, если руководитель его не правил. Правку руководителя код не затирает.
4) Выгрузить/восстановить: «Обновления» → «База знаний ИТК» → «Выгрузить базу знаний» / «Загрузить из архива». В архиве README и 00_podskazka_dlya_ii.md — её вставляют новой модели как системную подсказку.
5) Другая модель для «Фила»: там же «Подключить другую модель» (OpenAI-совместимый адрес, модель, ключ) → «Фил думает этой моделью». Не ответила — сам вернётся к DeepSeek.
6) Копии каждый день: хостинг + S3 (kb_ДАТА.zip в ночной копии), Сингапур (/var/backups/kosmos/kb), Гуанчжоу (забирает ночные копии). Гонконга пока нет.
