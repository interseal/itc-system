# ИТК · «Космос» — устройство, что готово и как запустить

Версия 2 от 13.11.2026. Секретов в документе нет.

---

## 1. Что такое «Космос»

- Второй ИИ-помощник ИТК, рядом с «Филом». Думает только на Claude (Anthropic). «Фил» остаётся на DeepSeek и других моделях и не меняется.
- Отдельное приложение: «Фил» и «Космос» работают независимо и одновременно. Каждому можно дать свою задачу.
- Пользуются руководитель и сотрудники. Вход тем же пропуском, что в Экосистеме.
- Ключ Claude — сменная деталь. Ключей от разных аккаунтов можно держать несколько, работает один, активный. Память, переписка и задачи хранятся на сервере «Космоса» и от ключа не зависят: сменили ключ — «Космос» продолжает с того же места.

---

## 2. Где что работает

| Часть | Адрес | Что делает |
|---|---|---|
| Сервер «Космоса» | kosmos.itcpartner.store, Aliyun **Сингапур** (ещё не создан) | Claude, память, переписка, задачи, ключи, экран «Космоса» |
| Страница в магазине | itcpartner.store/apps/kosmos/ | «Космос» и «Фил» рядом. Руководителю — подключение сервера по шагам и его состояние |
| Связь магазина с сервером | itcpartner.store/api/kosmos.php | проверка пропусков, одноразовая установка, новые версии, отчёты сервера, ночные копии |

Почему Сингапур: Anthropic разрешает Claude только из поддерживаемых стран. Россия, материковый Китай и Гонконг в список не входят, поэтому Claude не работает с хостинга reg.ru и с серверов в Гуанчжоу и Гонконге. Кыргызстан и Сингапур в списке есть.

Правило Anthropic о людях: пользоваться Claude можно, находясь в поддерживаемой стране. Поэтому доступ к «Космосу» даётся сотрудникам, которые работают из таких стран. Склад в Китае по умолчанию без доступа. В Китае и России остаётся «Фил».

## 3. Что уже сделано (версия 0.1.0)

Код написан и проверен у помощника. Проверок 123, все прошли. Claude в проверках заменял пробный «двойник». Настоящий Claude проверим на сервере в Сингапуре.

**Разговор**
- Чат как у «Фила»: список разговоров, поиск, переименование, удаление. Ответ появляется по мере написания.
- Работает на компьютере и телефоне.
- Ответы оформлены: заголовки, списки, таблицы. Кнопка «Скопировать».

**Быстро, потом глубоко** (чего не хватало «Филу»)
- Быстрая модель (Haiku 5.5) отвечает сразу.
- Долгую работу она сама передаёт сильной модели (Sonnet 5.5, можно Opus). Сильная работает в фоне, шаги видны, результат приходит в тот же разговор.
- Кнопка «Долгая задача» — сразу в фон, без быстрого ответа.
- Задачу в очереди можно отменить. Длинные разговоры «Космос» сам сжимает в сводку, чтобы не дорожали.

**Память**
- О компании: общее знание для всех, записывает руководитель.
- О человеке: личное, видят только сам сотрудник и руководитель.
- В разговоре: «запомни…», «забудь…», «что мы решали про…». Память видна и правится в окне «Память».

**Ключи Claude (только руководитель)**
- Добавить ключ с названием (например «Аккаунт 2»). При добавлении ключ сразу проверяется.
- Сделать активным, проверить, переименовать, удалить.
- Понятные ошибки: ключ не подходит, на счёте аккаунта кончились деньги, Claude перегружен.
- Ключ хранится только на сервере, зашифрованным. Обратно не показывается, видны только последние 4 знака.
- Расход по каждому ключу и модели за 30 дней.

**Сотрудники и расходы (только руководитель)**
- Кто пользуется: все сотрудники или только отмеченные. Склад по умолчанию без доступа.
- Список сотрудников, открывавших «Космос». Каждому можно открыть или закрыть доступ.
- Лимит сообщений в день на сотрудника (по умолчанию 150). У руководителя лимита нет.
- Защита от случайных повторов: не больше 20 сообщений в минуту.
- Выбор моделей для быстрых ответов и для долгих задач.

**Сервер**
- Установка одной командой с одноразовым кодом. Служебный ключ сервера создаётся при установке. В магазине хранится только его отпечаток.
- Сам получает сертификат https, когда заработает запись DNS.
- Раз в минуту сообщает магазину, что жив. Руководитель видит это на странице «Космоса».
- Новые версии берёт из магазина и ставит только с верной подписью (ключ KOSMOS_SIGN_KEY).
- Каждую ночь (03:00–05:00 по Бишкеку) копирует базу в магазин. Хранятся 7 последних копий.
- Если сервер сломается: новый сервер + та же команда установки, память поднимется из ночной копии сама. Ключи Claude после этого нужно вставить заново, из сейфа.

**Страница в магазине** — itcpartner.store/apps/kosmos/
- На компьютере «Космос» слева и «Фил» справа. Переключатель «Космос / Фил / Рядом». Переключение не прерывает работу ни одного из них.
- На телефоне — один помощник на экране, переключение сверху.
- Пока сервер не готов, руководитель видит пять шагов подключения с отметками. Сотрудники видят «подключается».

## 4. Запуск — по шагам

1. **Номер обновления.** Руководитель называет номер последнего установленного обновления (Экосистема → Обновления).
2. **Сейф.** Руководитель входит в Bitwarden во встроенном браузере. Помощник создаёт ключ подписи версий KOSMOS_SIGN_KEY, кладёт его в сейф (проект `dev`) и собирает обновление магазина с «Космосом».
3. **Обновление.** Руководитель ставит его с телефона, как обычно.
4. **Сервер.** Aliyun → 轻量应用服务器 → 创建服务器 → регион 新加坡 (Сингапур) → Ubuntu 24.04 → 2 ядра, 2–4 ГБ памяти, диск от 40 ГБ. Прислать снимок с IP и сроком оплаты.
5. **Установка.** Открыть itcpartner.store/apps/kosmos/ → «Получить команду установки» → «Скопировать команду».
   Затем Aliyun → сервер в Сингапуре → 远程连接 → 立即登录 → вставить команду → Enter.
   Дождаться строки «Космос: готово» (3–5 минут), прислать снимок.
6. **Адрес.** В reg.ru → домен itcpartner.store → DNS добавить запись: тип **A**, имя **kosmos**, значение — IP сервера. Можно сделать вместе во встроенном браузере.
7. **https.** Сервер получит сертификат сам, в течение 10 минут после того, как заработает запись.
8. **Ключ Claude.**
   - console.anthropic.com → API Keys → Create Key. Оплата Claude API идёт отдельно от подписки claude.ai: по расходу, со счёта аккаунта в консоли.
   - Открыть «Космос» → Настройки → Ключи Claude → вставить ключ.
   - Копию ключа положить в сейф: CLAUDE_KEY_<название аккаунта>.
   - Для запаса ключ второго аккаунта добавляется так же.
9. **Проверка.** Короткий вопрос, «запомни…», долгая задача, смена ключа — память на месте.

## 5. Что дальше, по этапам

**Этап 2б. Кнопка в CRM**
- На главном экране Экосистемы под кнопкой «Фил» появится кнопка «Космос».
- Нужен свежий код: Экосистема → Обновления → «Файлы для Claude». Копия на ноутбуке устарела.
- До этого «Космос» открывается по адресу itcpartner.store/apps/kosmos/. Его можно добавить на главный экран телефона.

**Этап 3. Данные Экосистемы**
- «Космос» начнёт видеть и менять сделки, задачи, клиентов, поставщиков, заказы, грузы. Деньги — только руководителю.
- Переписка с фабриками WeCom, КП в PDF и Excel через готовый инструмент «Фила», поиск клиентов в интернете.
- Каждое изменение данных — с журналом. Важные действия — после подтверждения.

**Этап 4. Голос**
- Голосовой ввод и ответ голосом через Яндекс SpeechKit. Ключ уже есть у «Фила».

**Этап 5. Своё приложение на телефоне**
- Обёртка из проекта ITCApp, как у «Фила»: значок, уведомления о готовых задачах.

**Этап 6. Картинки**
- Задачи для «Рисовалки»: карточки товаров, баннеры.

## 6. Деньги и безопасность

- **Расход Claude.** Платит аккаунт того ключа, которым сделан запрос. Руководитель видит расход в настройках «Космоса» (раздел «Расход»), а точную сумму — в консоли Anthropic.
- **Дешевле.** Быстрая модель отвечает на простое. Длинные разговоры сжимаются в сводку. Правила «Космоса» помечены для кеша Claude, повторная часть запроса стоит дешевле.
- **Ключи Claude** живут только на сервере, зашифрованные. В магазин, в обновления и в переписку не попадают.
- **Сейф.** Новые секреты:
  - KOSMOS_SIGN_KEY — подпись версий;
  - CLAUDE_KEY_* — по одному на каждый аккаунт;
  - SERVER_SG_HOST — IP сервера.
- **Копии базы** лежат в магазине, в закрытой папке со случайным именем. Ключей Claude в них нет в открытом виде.

## 7. «Фил» — что улучшить (разобрать после запуска «Космоса»)

Мысли руководителя от 13.11.2026:
- **Два DeepSeek.** Быстрый сразу отвечает, сложное передаёт полному, чтобы «Фил» не молчал, пока думает. В «Космосе» эта схема уже работает. Её можно перенести.
