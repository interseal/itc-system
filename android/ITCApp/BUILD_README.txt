================================================================
ИТК Мебель — Android-обёртка (WebView) для itcpartner.store
Для сборки APK и публикации в RuStore
================================================================

ЧТО ЭТО
----------------------------------------------------------------
Нативное Android-приложение, которое открывает твой PWA
https://itcpartner.store/ во весь экран, как приложение:
без адресной строки, с обработкой кнопки «назад», загрузкой
файлов и камерой (поиск по фото / сканер QR), а внешние ссылки
(tel:, mailto:, чужие домены, WhatsApp и т.п.) открываются
в системных приложениях.

  applicationId : store.itcpartner.app
  Название      : ИТК Мебель
  minSdk 23 (Android 6+), targetSdk 34
  Иконка        : логотип-глобус ИТК (адаптивная + legacy mipmap)


КАК СОБРАТЬ APK (Android Studio)
----------------------------------------------------------------
1. Распакуй архив. Открой Android Studio → Open → выбери папку ITCApp.
2. Дай студии докачать Gradle/SDK при первом синке (Sync Now).
   Если попросит — согласись установить нужный SDK Platform 34.
3. Сборка debug-APK для теста:
   Build → Build Bundle(s)/APK(s) → Build APK(s).
   Готовый файл: app/build/outputs/apk/debug/app-debug.apk
4. Сборка ПОДПИСАННОГО релиз-APK (нужен для RuStore):
   Build → Generate Signed Bundle / APK → APK →
   Create new… (создай keystore: путь, пароль, alias — СОХРАНИ их,
   они понадобятся для всех будущих обновлений!) →
   вариант release → Finish.
   Готовый файл: app/build/outputs/apk/release/app-release.apk


ПУБЛИКАЦИЯ В RUSTORE
----------------------------------------------------------------
1. console.rustore.ru → вход по VK ID, верификация как юрлицо (ИТК).
2. «Приложения» → «Добавить приложение» → название «ИТК Мебель»,
   тип «бесплатное».
3. Загрузи app-release.apk, иконку 512×512 (файл play_store_icon_512.png
   в корне этого архива), скриншоты, описание, категорию, возрастной
   рейтинг.
4. Отправь на модерацию. После одобрения приложение появится в RuStore.
   Публикация бесплатна, комиссии за внешние платежи (Robokassa) нет.


ЧТО МОЖНО ПОМЕНЯТЬ
----------------------------------------------------------------
- Имя приложения: app/src/main/res/values/strings.xml (app_name).
- Пакет (если нужен другой): applicationId в app/build.gradle
  и namespace там же; имя папки java/store/itcpartner/app — под пакет.
- Стартовый адрес/домен: константы HOST и START_URL в начале
  MainActivity.java.


ВАЖНО ПРО PUSH-УВЕДОМЛЕНИЯ
----------------------------------------------------------------
WebView сам по себе НЕ показывает Web Push так, как браузер.
Уведомления «к вам едет заказ» в нативной обёртке надо делать
тем же способом, что в PlaneApp — нативный foreground-сервис
с опросом сервера (FCM в Китае заблокирован). В этой версии v1
push не подключён — это отдельный шаг, сделаем при необходимости.


ПРИМЕЧАНИЕ
----------------------------------------------------------------
gradle-wrapper.jar в архив не вложен (бинарник). Android Studio
сам настроит wrapper при первом открытии проекта — собирать через
GUI (меню Build), это не требует ручной установки Gradle.
