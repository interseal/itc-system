# Эталон значков Android-приложений ИТК

Утвердил руководитель 14.11.2026: «все ярлыки одинаковые», вид как на `etalon_vse.png`. Выбран **крупный вариант**: шар почти во весь значок, у фото белая рамка идёт по самому краю значка. Так показывает телефон по стандарту Android: видна середина слоя, 72 из 108dp. Некоторые оболочки обрезают немного сильнее.
Каждое новое или изменённое приложение сверяется с этим эталоном. Пропорции важнее размеров в пикселях.

## Пропорции (передний слой адаптивного значка, полотно 432×432 = 108dp)

| Вид | Пример | Где содержимое | Доля полотна |
|---|---|---|---|
| **shar** — белый шар ИТК на цвете | Экосистема, Переводчик, CRM | 68…364 по обеим осям, по центру | 68,5 % |
| **shar** (цветной шар на белом) | ITC GLOBAL | то же | 68,5 % |
| **foto** — фото в белой рамке | Фил, Космос | рамка 60…371, белая рамка 16 px по краю видимой части, внутри мягкое белое свечение | 72 % |
| **logo** — любой другой знак | — | вписан в тот же квадрат, что и шар | 68,5 % |

Правила:
1. Фон — **один цвет во весь значок** (`ic_flv_bg` в `values/strings.xml`). Никаких квадратов и кругов с фоном внутри переднего слоя: иначе по краям торчат белые или цветные поля.
2. Шар во всех приложениях **одного размера** — как у «Экосистемы».
3. Фото людей — только в рамке по образцу «Фила». Фон у таких значков приглушённый: Фил `#A39D88`, Космос `#8090A3`.
4. Старые значки (`mipmap-*/ic_launcher*.png`) делаются из того же слоя автоматически.

## Файлы

- `shar_maska.png` — форма белого шара нужного размера.
- `shar_cvetnoy.png` — цветной шар (ITC GLOBAL).
- `foto_okno.png` — окно под фото.
- `foto_ramka.png` — белая рамка.
- `foto_v_ramke_obrazec.png` — образец «Фил».
- `etalon_vse.png` — как выглядят все значки.

## Команды

    python3 kosmos/tools/icon_kit.py make --key <имя> --kind shar|foto|logo [--image файл] --color "#RRGGBB"
    python3 kosmos/tools/icon_kit.py check      # проверить все приложения на эталон

`new_android_app.py` уже делает значок через `icon_kit` (`--kind`).

## Ещё не приведены к эталону

draw, esim, hotels, metro, nav, trade. У них своя рисованная картинка со скруглённым квадратом внутри. Ждут решения руководителя, переделывать ли их под эталон: `check` их отмечает.
