# Эталон значков Android-приложений ИТК

Утвердил руководитель 14.11.2026: «все ярлыки одинаковые», вид как на `etalon_vse.png`, **верхний ряд**. Нижний ряд показывает, как значки обрежут телефоны Samsung: пропорции подобраны так, чтобы на любом телефоне был «верхний» вид.
Каждое новое или изменённое приложение сверяется с этим эталоном. Пропорции важнее размеров в пикселях.

## Пропорции (передний слой адаптивного значка, полотно 432×432 = 108dp)

| Вид | Пример | Где содержимое | Доля полотна |
|---|---|---|---|
| **shar** — белый шар ИТК на цвете | Экосистема, Переводчик, CRM | 102…330 по обеим осям, по центру | 52,8 % |
| **shar** (цветной шар на белом) | ITC GLOBAL | то же | 52,8 % |
| **foto** — фото в белой рамке | Фил, Космос | рамка 96…335, белая рамка 14 px, внутри мягкое белое свечение | 55,3 % |
| **logo** — любой другой знак | Рисовалка, eSIM, Отели, Trade | большая сторона 200, по центру; фон можно градиентом во весь слой | 46 % |

Правила:
1. Фон — **один цвет во весь значок** (`ic_flv_bg` в `values/strings.xml`). Никаких квадратов и кругов с фоном внутри переднего слоя: иначе по краям торчат белые или цветные поля.
2. Шар во всех приложениях **одного размера** — как у «Экосистемы».
3. Фото людей — только в рамке по образцу «Фила». Фон у таких значков приглушённый: Фил `#A39D88`, Космос `#8090A3`.
4. Старые значки (`mipmap-*/ic_launcher*.png`) делаются из того же слоя автоматически.

## Файлы

## Команды

    python3 kosmos/tools/icon_kit.py make --key <имя> --kind shar|foto|logo [--image файл] --color "#RRGGBB"
    python3 kosmos/tools/icon_kit.py check      # проверить все приложения на эталон

`new_android_app.py` уже делает значок через `icon_kit` (`--kind`).

## Все приложения (14.11.2026)

- **shar** — белый или цветной шар ИТК, 52,8 %: Экосистема, Переводчик, CRM, ITC GLOBAL, Склад в Китае (коричневый `#795547`, как на сайте).
- **foto** — фото в белой рамке, 55,3 %: Фил, Космос.
- **logo** — знак размером 200 из 432 (46 %) на фоне-градиенте во весь значок, без квадрата внутри: Рисовалка, eSIM, Отели, Alex Trade. У Навигатора стрелка 185: руководитель просил крупнее прежней, но не во весь значок.
- **картина без рамки** — Мой Гуанчжоу: фото башни, 304 из 432, тёмный фон под ним.

Значки на сайте лежат в `store/apps/<имя>/icon-192.png` и `icon-512.png` (eSIM — в `store/esim/`). Это та же картинка: видимая часть значка со скруглёнными углами.
