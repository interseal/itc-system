# Обновления, которые собирает сервер «Космоса»

С №545 (сервер 0.3.7) ноутбук для сборки не нужен. Claude кладёт сюда файл `<N>.json`:

```json
{"n": 546, "title": "Коротко, что это", "what": ["пункт для руководителя"], "files": ["store/eco/…", "store/api/…"], "kosmos": true}
```

- `files` — какие файлы из этого хранилища положить в обновление (пути как в обновлении: store/…, site/…, metro/…).
  store/api/kosmos.php и store/apps/kosmos/index.html кладутся всегда.
- `kosmos: true` — добавить пакет сервера «Космоса» (версия — из kosmos/lib/boot.php).

Сервер раз в 10 минут забирает GitHub, собирает obnovlenie_N.zip (kosmos/tools/build_store_update.py), подписывает
ключом обновлений и своим ключом «Космоса» и отдаёт в магазин. Руководитель видит на странице «Обновления»
«Готово к установке: обновление №N» и ставит одной кнопкой. Ошибка сборки — красной строкой там же.
Номер — строго следующий после установленного; один файл = одно обновление, повторно не собирается.

## Android-приложения (с №551, сервер 0.4.1)

```json
{"n": 552, "title": "…", "what": ["…"], "files": [], "kosmos": false,
 "android": {"apps": ["fil", "kosmos"], "code": 27, "name": "2.2.4", "notes": "Что нового — увидят люди при обновлении"}}
```

- Проект — android/ITCApp (13 приложений, список: `python3 kosmos/tools/build_android.py --project android/ITCApp --list`).
- `apps` — имена вариантов или `"all"`; не больше 6 за раз (магазин принимает обновление до 60 МБ).
- `code` — больше прежнего (на 14.11.2026 у всех 26), `name` — «2.2.4».
- Сервер в фоне (5–20 минут, первый раз дольше — ставит Java/SDK/Gradle) собирает и подписывает ключом ИТК из сейфа «Авто»,
  кладёт в обновление `store/app/<имя>/itc-<имя>.apk` + `version.json` (у store — store/app/, у sklad — store/sklad/app/).
  Пока идёт сборка, на странице «Обновления» — «собираю Android-приложения».
- Новое приложение: `python3 kosmos/tools/new_android_app.py --key … --title … --url … [--icon значок.png] [--color #RRGGBB]`.
- Правки настроек сборки (*.gradle, *.properties в android/, build_android.py, agent.php), сделанные «Космосом»/Филом, ждут решения руководителя: кнопка «Одобрить» в настройках «Космоса» → «Разработчик» или ответ Филу/«Космосу».
- RuStore: APK из обновления руководитель загружает в console.rustore.ru (приложения там проверяют вручную).
